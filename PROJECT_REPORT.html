Student Management REST API

Java Programming — End Semester Practical Assignment
Project: Student Management System REST API
Technology: Spring Boot 3, JPA & MySQL
Server Port: 8080
Base URL: http://localhost:8080/api/students

1. Entity Requirements

The Student entity represents students enrolled in courses, mapped to the MySQL students table using Spring Data JPA.

Attribute Data Type Constraints & Description
id Long Primary Key, Auto-incremented (@Id, @GeneratedValue(strategy = GenerationType.IDENTITY))
name String Student's full name (Mandatory, @NotBlank)
email String Unique email address (@NotBlank, @Email, unique = true)
course String Enrolled course name (@NotBlank)
age Integer Student's age (@NotNull, @Min(1))

2. REST API Endpoints Specification

Method Endpoint Description Status Code
POST /api/students Add a new student 201 Created
GET /api/students Retrieve all students 200 OK
GET /api/students/{id} Retrieve student by ID 200 OK (or 404 Not Found)
PUT /api/students/{id} Update student details 200 OK (or 404 Not Found)
DELETE /api/students/{id} Delete a student by ID 200 OK (or 404 Not Found)
GET /api/students/course/{course} Retrieve students filtered by course 200 OK

3. Database Configuration (MySQL)

Configured in src/main/resources/application.properties:

spring.datasource.url=jdbc:mysql://localhost:3306/student_db?useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true&createDatabaseIfNotExist=true
spring.datasource.username=root

5. Exception Handling Architecture

Centralized exception handling is implemented using @RestControllerAdvice in GlobalExceptionHandler.java:

  • ResourceNotFoundException: Thrown whenever a student ID does not exist in MySQL. Returns HTTP 404 Not Found with timestamp, path, and error message.
  • MethodArgumentNotValidException: Catches validation errors (e.g. blank name, invalid email format, negative age) triggered by @Valid. Returns HTTP 400 Bad Request.
  • Exception: Handles unexpected runtime server exceptions with HTTP 500 Internal Server Error.
